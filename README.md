## Projects

### To-Do List

A task management application built with vanilla JavaScript.

Features include:

- Creating tasks
- Completing tasks
- Deleting tasks
- Persistent data with `localStorage`

Repository:

https://github.com/Oleh-Koliadiuk/To-Do-List

### Auto Shorts Generator

A Python-based automation pipeline for creating vertical videos for platforms such as YouTube Shorts, Instagram Reels and TikTok.

The project combines:

- Video processing
- Chroma key
- Image processing
- Automatic subtitles
- AI-powered speech recognition

Repository:

https://github.com/Oleh-Koliadiuk/Auto-Shorts-Generator

### Generate Quotes

A minimalist quote generator built with vanilla JavaScript.

Features include:

- Quote generation
- Theme switching
- Clipboard support
- Generation statistics
- Persistent state with `localStorage`

Repository:

https://github.com/Oleh-Koliadiuk/Generate-Quotes
